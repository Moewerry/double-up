# DoubleUp

奶油蜜桃色的数字合并游戏，适配手机与桌面。只有首页和关卡页，从当前关开始，通关后顺序进入下一关，没有选关入口。

当前是前 5 关开发预览，配置与交互尚待运行验证，不代表 20 关正式版。后续关卡没有作为可解锁内容发布。

## 环境与命令

Node.js 22.12+，建议 Node.js 24 LTS；npm，依赖版本记录在 package-lock.json。

```powershell
cd double-up
npm ci
npm run dev
```

由项目所有者按需执行检查和构建：

```powershell
npm run typecheck
npm run build
npm run preview
```

实现过程中未启动项目、执行编译、构建、语法检查或测试。当前没有配置测试脚本。

## 操作

- 手机在棋盘上滑动；桌面使用方向键或 WASD。设置中可以显示方向按钮。
- 相同数字相遇时合并，每个方块单步只合并一次；无效移动不计步、不生成方块。
- 每局一次撤销，失败后仍可使用，通关后不可使用。重开恢复固定初始局面。
- 首页恢复当前局面，通关后通过结果弹窗进入下一关。第五关显示预览章节完成，可重玩本关。
- 音效默认关闭，可在设置中开启。

## 存档

localStorage 使用 `double-up:save:v1` 单键原子写入局面、撤销快照、通关记录与设置。有效移动先保存逻辑结果，再展示动画。存档仅限当前浏览器与站点，多标签页改写后暂停输入，需要刷新读取最新进度。

不兼容版本不会自动覆盖；损坏的当前局面重新开始，尽可能保留连续有效的历史纪录。存储异常时界面会提示无法保存。

## 验收与部署

需人工验证四向移动、一次合并规则、无效输入、撤销后相同方向复现、刷新恢复、顺序闯关、结算关闭后重新查看、多指手势、快速输入及 320–430px 手机布局。前 5 关需通过正式引擎回放与人工试玩验证后，才能作为正式关卡发布。

纯静态部署，构建命令 `npm run build`，输出目录 `dist`。使用 HashRouter，无需额外配置页面路径回退。子路径托管时按实际公开地址配置 Vite `base`。

通用组件来自 [shadcn/ui 官方注册表](https://ui.shadcn.com)，布局使用 Tailwind CSS 4。棋盘与数字方块是游戏专有展示组件。
